# 🩸 Blood Bank Management System

This project is a Blood Bank Management System developed using Flask (Python) and MySQL. It helps manage donor details, blood requests, and provides an admin dashboard for monitoring the system.

## 🚀 Features

- Donor Registration and Management
- Blood Request Management
- Admin Dashboard with statistics
- Displays Pending and Completed Requests
- Data stored and managed using MySQL
- Simple and user-friendly interface using Bootstrap

## 🛠️ Technologies Used

- Frontend: HTML, CSS, Bootstrap
- Backend: Python (Flask)
- Database: MySQL

## 📊 Functional Modules

- Donor Module
- Patient Module
- Blood Request Module
- Staff Management
- Dashboard Analytics

## 🎯 Objective

To efficiently manage blood donor records and blood requests, ensuring proper tracking and availability of blood units.

## 💡 Future Enhancements

- User authentication system
- Real-time notifications
- Advanced search and filtering
- Deployment on cloud
